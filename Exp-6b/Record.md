Experiment 6(b): Shape Demo Using Packages

## Aim

To write a Java program using a user-defined package to calculate the area and perimeter of a circle, triangle, and square.

## Algorithm

1. Start the program.
2. Create a package named Exp6b.
3. Create a Circle class to calculate the area and perimeter of a circle.
4. Create a Triangle class to calculate the area and perimeter of a triangle using its three sides.
5. Create a Square class to calculate the area and perimeter of a square.
6. Create the ShapeDemo main class.
7. Create objects for all three shapes and call their methods.
8. Display the area and perimeter of each shape.
9. Stop the program.

## Program

The program consists of four Java files:

Circle.java Triangle.java Square.java ShapeDemo.java

## Result

Thus, the Java program to calculate the area and perimeter of a circle, triangle, and square using a user-defined package was written successfully.
